# Tarefa Operadores Aritméticos
Operadores Aritméticos no NodeJS

Abra seu Node.js (no próprio VSCode ou no aplicativo Node.js instalado).

A seguir, faça os exercícios usando os operadores abaixo:

---

## ➕ Operador + (Adição / Soma)

Exemplo:

```js
5 + 3
```

Resultado esperado:

```
8
```

---

## ➖ Operador - (Subtração)

Exemplo:

```js
10 - 4
```

Resultado:

```
6
```

---

## ✖ Operador * (Multiplicação)

Exemplo:

```js
6 * 3
```

Resultado:

```
18
```

---

## ➗ Operador / (Divisão)

Exemplo:

```js
12 / 4
```

Resultado:

```
3
```

---

## 🧩 Operador % (Resto da divisão)

Exemplo:

```js
10 % 3
```

Resultado:

```
1
```

Por quê?

- 10 dividido por 3 é igual a 3  
- 3 × 3 = 9  
- **10 − 9 = 1** (este é o resto)

## 🧩 operador Exponenciação ** 
Exemplo: 

´´´ js
2 ** 3 
´´´
Resultado 

´´´
