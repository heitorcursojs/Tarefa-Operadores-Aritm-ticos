# Tarefa Operadores Aritméticos
Operadores Aritiméticos no NodeJS 

Abra seu nodejs pode ser no prórpio VSCode ou no aplicativo NodeJs instalado na sua máquina.

A seguir faça os exercícios usando os operadores abaixo;

# Operador + Adição ou  seja Soma

'Ex: no terminal rode 5 +3 resultado = 8'

# Operador - Subtração 
'Ex: no terminal rode 10 - 4 '
resultado = 6

# Operador de multiplicação 
'Ex:  no terminal rode 6 * 3 '
resultado = 18

# Operador de Divisão 
'Ex: no terminal rode 12 / 4 '
resultado = 3

# operador Retorna resto da divisão 
Ex: 'rode no  terminal 10% 3 '
resultado = 1 
Porque 10 divido 3 é 9 o que sobra ? 
Quando você usa esse operador ele te mostra o  resto o que sobra.

# Operador Exponenciação - Eleva um  valor ao outro 
'Ex: 2 ** 3 '
resultado  = 8 
Explicação : 2 é a base 3 é expoente ou seja o número 2 é multiplicado por ele mesmo  3 vezes.

'2 X 2 X 2  = 8 ' 
 passo a passo: 
 Primeiro : 
'2 x 2  = 4  '

 Depois: 
'4 x 2 = 8  '
resultado final = 8
